## English

**ConsolePad 0.14.0-beta** — shaders that work with split screen.

- ConsolePad now keeps an Iris shader pack on with several players when the pack is **safe for split screen** (it carries the file `shaders/consolepad-splitscreen-safe`). Every other pack is still turned off while extra players are in and back on when one is left. `"keepShaders": true` in `config/consolepad/split.json` keeps any pack on.
- New separate download: **ConsolePad Lite**, a tiny shader pack with richer colour (saturation, contrast and warmth can be changed in Iris). It looks the same in every player's region and costs the same as an empty pack.

Requires Minecraft 1.21.1, NeoForge 21.1.x and Java 21. Remove older versions from `mods`.

## Español

**ConsolePad 0.14.0-beta** — shaders que funcionan con la pantalla dividida.

- ConsolePad deja ahora puesto un pack de shaders de Iris con varios jugadores cuando el pack es **seguro para la pantalla dividida** (lleva el archivo `shaders/consolepad-splitscreen-safe`). Los demás se siguen apagando mientras haya jugadores extra y vuelven al quedar uno. Con `"keepShaders": true` en `config/consolepad/split.json` se deja puesto cualquier pack.
- Descarga nueva aparte: **ConsolePad Lite**, un pack de shaders muy pequeño con más color (la saturación, el contraste y la calidez se cambian en Iris). Se ve igual en la región de cada jugador y cuesta lo mismo que un pack vacío.

Requiere Minecraft 1.21.1, NeoForge 21.1.x y Java 21. Quita las versiones anteriores de `mods`.
